# 社内イベントページ（有限会社ツーボックス）

Facebook投稿の「いいね！」数を競う社内イベント向け、シングルページのテンプレートです。開催期間は毎年 10/15–10/31 を想定し、開始前/開催中/終了後を自動判定するカウントダウンを搭載しています。

## 主な機能

### 📊 ランキング表示
- **現在のトップ3（表彰台）**: 期間中の通算順位（1-3位）をメダル付きで表示
- **4-10位**: シンプルな一覧形式で表示
- **前日比較**: 前日順位との比較を矢印（↑↓←）で表示
  - ↑ 青: ランクアップ
  - ← 白: 変動なし
  - ↓ 赤: ランクダウン
  - NEW 黄: 初登場

### 📸 昨日のトップ3投稿
- 昨日だけのいいね数トップ3を別途表示
- 投稿のスクリーンショット + 投稿者名 + いいね数
- クリックでFacebookグループページへ遷移
- 通算ランキング外の人も「プチバズった」ことが分かり、参加意欲向上

### ⏱️ カウントダウン
- イベント開始までのカウントダウン
- イベント終了までのカウントダウン
- イベント終了後は紙吹雪アニメーション（5秒間）

### 🎨 その他
- ダークテーマ/グラス風UI
- レスポンシブ対応（PC・タブレット・スマホ）
- 会社ロゴ表示（フォールバック機能付き）

## 使い方

### 基本セットアップ

1. **ロゴ画像を配置**:
   - `assets/logo.png` として会社ロゴを保存

2. **画像を準備**（詳細は [IMAGE_GUIDE.md](IMAGE_GUIDE.md) を参照）:
   - `assets/daily-post-1.jpg` - 昨日のトップ3投稿（1位）
   - `assets/daily-post-2.jpg` - 昨日のトップ3投稿（2位）
   - `assets/daily-post-3.jpg` - 昨日のトップ3投稿（3位）

3. **管理画面でデータを更新**:
   - `admin.html` にアクセス
   - パスワード: `tsubox-admin`
   - ランキング（1-10位）と昨日のトップ3投稿を入力
   - GitHubトークンを入力して保存

### 管理画面の使い方

#### ログイン
1. `admin.html` にアクセス
2. パスワード: `tsubox-admin` を入力
3. ログインをクリック

#### ランキング管理（1-10位）
1. 対象日付を選択（デフォルトは今日）
2. GitHubトークン（repo権限）を入力
3. 1-10位の氏名を入力
4. 前日順位を入力（新規の場合は空欄）
   - 入力すると自動で矢印がプレビュー表示されます
5. 「GitHubに保存」をクリック

#### 昨日のトップ3投稿
1. 1-3位の投稿者名を入力
2. いいね数を入力
3. 画像ファイル名を入力（例: `assets/daily-post-1.jpg`）
4. 「GitHubに保存」をクリック

データは数十秒後にサイトへ反映されます。

## データ構造

### rankings.json（通算ランキング）
```json
{
  "2025-10-24": [
    {
      "rank": 1,
      "name": "山田太郎",
      "prevRank": 2
    }
  ]
}
```

### daily-top3.json（昨日のトップ3投稿）
```json
{
  "2025-10-24": [
    {
      "rank": 1,
      "name": "佐藤花子",
      "likes": 245,
      "postImage": "assets/daily-post-1.jpg"
    }
  ]
}
```

## 日付ロジック

- `script.js` で「次に来る10月」を自動判定します。
  - 現在が10/31を過ぎていれば翌年、そうでなければ今年を対象年にします。
  - 日本時間（JST, +09:00）で `10/15 00:00:00` から `10/31 23:59:59` を計算します。
  - 開始前は「開始まで」、開催中は「終了まで」、終了後はメッセージを表示します。

## トラブルシューティング

### ランキングが表示されない

1. **データファイルを確認**:
   - `rankings.json` と `daily-top3.json` が存在するか確認
   - JSON形式が正しいか確認（カンマの位置など）

2. **ブラウザの開発者ツールで確認**:
   - F12キーを押す
   - Consoleタブでエラーメッセージを確認
   - Networkタブでファイルが読み込めているか確認

### 画像が表示されない

1. **ファイル名を確認**:
   - 大文字小文字が正確か（`daily-post-1.jpg` であり `Daily-Post-1.JPG` ではない）
   - パスが正しいか（`assets/daily-post-1.jpg`）

2. **画像ファイルが存在するか確認**:
   - `assets/` フォルダに画像ファイルがあるか確認
   - ファイルサイズが大きすぎないか確認（推奨: 500KB以下）

詳細は [IMAGE_GUIDE.md](IMAGE_GUIDE.md) を参照してください。

### 管理画面で保存できない

1. **GitHubトークンを確認**:
   - トークンに `repo` 権限があるか確認
   - トークンが有効期限切れでないか確認

2. **ブラウザのConsoleでエラーを確認**:
   - F12キーを押してConsoleタブを開く
   - エラーメッセージを確認
